`main.py` (standard library only) writes the GPS's one-line excuse for
sending the driver down the wrong road to `/output/entry.txt`.

The line (103 characters, single line, plain text):

> The map sent us to a wedding in a cul-de-sac. The bride waved. The groom cried. I'm the one in trouble.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
